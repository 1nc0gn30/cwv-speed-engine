CLI Commands Quick Reference

Terminal Commands cwv-speed 
# 1. Audit a live URL
cwv-speed audit https://example.com --device mobile

# 2. Optimize an HTML file
cwv-speed optimize input.html -o output.html --hero-preload

# 3. Launch CWV Speed Studio (Web UI)
cwv-speed ui --port 8448 --open

# 4. Run CI/CD Performance Gate
cwv-speed ci-gate https://staging.example.com --min-score 90 --max-cls 0.05

# 5. Start MCP Server for Claude / Cursor
cwv-speed mcp
